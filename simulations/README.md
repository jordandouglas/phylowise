# Simulations

This folder contains scripts for simulating datasets and testing for associations between substitution rate and bioloigcal trait using PPC and PGLS.

`false/` contains a script for simulating under the null hypothesis where rates are not associated with traits


`power/` is the same but for positive associations between rate and trait


`newick/` contains the list of precomputed trees that are sampled from during these simulations
